# Credify UI References

These are implementation/inspiration references, not assets to copy.

## Product interaction references

### Linear
Useful for:
- calm high-density application layout
- strong navigation hierarchy
- keyboard-friendly workflows
- making secondary UI recede so the task surface dominates

https://linear.app/
https://linear.app/now/behind-the-latest-design-refresh

### Stripe Dashboard
Useful for:
- operational dashboard hierarchy
- detail pages that lead to actions
- at-a-glance activity summaries
- serious, non-theatrical financial software UI

https://support.stripe.com/topics/dashboard

### Vercel Dashboard
Useful for:
- settings / project navigation architecture
- concise system state presentation
- evaluator-style technical details without turning the whole interface into a developer tool

https://vercel.com/kb/dashboard
